# Extension Icons

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store, installation)

## Creating Icons

You can create simple icons using:
1. Online tools like https://www.favicon-generator.org/
2. Image editors like GIMP, Photoshop, or Figma
3. Use a shield or security-themed icon

## Temporary Solution

Until custom icons are created, Chrome will use a default placeholder icon.

## Icon Design Guidelines

- Use a simple, recognizable symbol (shield, lock, checkmark)
- Use colors that indicate security: blue, green, or a warning color scheme
- Make sure icons are clearly visible on both light and dark backgrounds
- PNG format with transparency
