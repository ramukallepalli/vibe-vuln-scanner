Privacy Policy — Vibe Vulnerability Scanner

Last updated: July 2026

Overview

Vibe Vulnerability Scanner is a Chrome extension that analyzes the security posture of web pages you visit. It operates entirely on your device. We do not operate any servers, collect personal data, or sell any information.

What the extension accesses

  • Page content — Scripts, cookies, HTTP headers, and DOM of the active tab are read locally to perform security analysis. This data never leaves your device except as described below.
  • Cookies — Cookie metadata (name, flags such as Secure/HttpOnly/SameSite) for the active tab is read to detect insecure cookie configurations. Cookie values are never read or transmitted.
  • Source maps — If a page exposes JavaScript source map URLs, the extension may fetch those map files to identify bundled dependencies. This is a direct browser fetch; no data passes through our servers.
  • Scan history — A summary of past scan results is stored locally in chrome.storage.local on your device. It is never uploaded anywhere.

Optional third-party data transmission

All third-party lookups are performed by your browser directly. No data passes through our servers.

  • OSV.dev — Package names and versions detected on a page are sent to the open-source OSV.dev API to check for known vulnerabilities. No personal data is included.
  • CISA KEV — The extension fetches a publicly available vulnerability catalog from cisa.gov. No data from your device is sent.
  • GitHub Advisory Database — Package names are queried against GitHub's public advisory API. No personal data is included.
  • Anthropic API (optional) — If you enable LLM-assisted analysis in Settings and provide your own Anthropic API key, small code snippets from the active page may be sent to the Anthropic API for analysis. This feature is disabled by default and requires explicit opt-in. Your API key is stored locally in chrome.storage.sync and is never transmitted to us. Anthropic's privacy policy applies to data sent to their API.

Data we do not collect

  • We do not collect names, email addresses, or any personally identifiable information.
  • We do not track browsing history.
  • We do not use analytics or advertising SDKs.
  • We do not sell or share any data with third parties.

Permissions explained

  • activeTab / tabs — Read the URL and content of the tab you are currently viewing, to perform the security scan.
  • cookies — Read cookie metadata for the active tab to check security flags. Values are never accessed.
  • scripting — Extract source map URLs embedded in page scripts to identify bundled dependencies.
  • storage — Save scan results and settings locally on your device.
  • webRequest — Capture HTTP response headers (CSP, HSTS, etc.) for security analysis.
  • downloads — Allow you to export scan results as JSON, CSV, or SARIF files.
  • <all_urls> — Required to scan any website you navigate to, not just a fixed list of domains.

Changes to this policy

If we make material changes, we will update the "Last updated" date above. Continued use of the extension after changes constitutes acceptance.
