NVD Integration Test Page

Test Cases

Case 1: Vulnerable jQuery Version (3.4.1)

  • Expected Result: CRITICAL severity finding
  • Confidence: high
  • Category: confirmed
  • Description: Should mention jQuery 3.4.1 is affected by CVE-2020-11022 or CVE-2020-11023
  • Evidence: Should include version range showing 3.4.1 falls within vulnerable range
  • Remediation: Should recommend updating to jQuery >= 3.5.0

Case 2: Safe jQuery Version (3.7.1) - Currently Commented Out

  • Expected Result: LOW severity informational finding
  • Confidence: medium
  • Category: informational
  • Description: Should mention jQuery 3.7.1 is outside vulnerable range
  • Remediation: Verify you're using latest stable release

How to Test

  1. Load this page with the Vibe Vulnerability Scanner extension enabled
  2. Open the extension popup
  3. Wait for scan to complete (may take a few seconds for NVD API calls)
  4. Verify the jQuery finding matches expected results above
  5. Check browser console (F12) and service worker console for any errors

Debugging Tips

  • Service Worker Console: chrome://extensions/ → "Inspect views: service worker"
    • Should see: "Fetched CVE details for CVE-XXXX-XXXXX"
    • Check for NVD API errors (rate limiting, network issues)
  • Content Script Console: F12 on this page
    • Look for KEV correlation activity
    • Check if library was detected correctly
  • Storage Check: In service worker console, run:
    • chrome.storage.local.get(null, console.log)
    • Verify KEV catalog is loaded
    • Check if CVE details are cached (keys like "cve_CVE-2020-11022")

Known jQuery KEV CVEs

  • CVE-2020-11022: jQuery XSS vulnerability (< 3.5.0)
  • CVE-2020-11023: jQuery XSS vulnerability (< 3.5.0)
