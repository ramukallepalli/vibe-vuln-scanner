Latest Version Check Test

Test Cases

Case 1: Outdated but Safe Version (jQuery 3.6.0)

  • Expected Result: LOW severity informational finding
  • Type: KEV_PRODUCT_SAFE_VERSION
  • Description: Should mention version is outside vulnerable range
  • Evidence:
    • detectedVersion: 3.6.0
    • latestVersion: 3.7.1 (or current latest)
  • Remediation: "Version 3.6.0 is safe but outdated. Latest stable version is 3.7.1. Consider updating."

Case 2: Latest Version (jQuery 3.7.1) - Currently Commented Out

  • Expected Result: LOW severity informational finding
  • Evidence:
    • detectedVersion: 3.7.1
    • latestVersion: 3.7.1
  • Remediation: "Version 3.7.1 is safe and up-to-date (latest stable release)."

How to Test

  1. Load this page with the extension enabled
  2. Open extension popup
  3. Wait for scan (may take 3-5 seconds for npm registry + NVD calls)
  4. Find the jQuery KEV_PRODUCT_SAFE_VERSION finding
  5. Verify:
    • Evidence shows both detectedVersion and latestVersion
    • Remediation tells you if version is outdated or up-to-date
    • No more generic "verify you're using the latest" message

Service Worker Console Checks

Open: chrome://extensions/ → "Inspect views: service worker"

  • Should see: "Fetched latest version for jQuery: 3.7.1" (or current latest)
  • Run: chrome.storage.local.get(null, console.log)
  • Verify key exists: latest_jquery with version and timestamp
  • Second scan should use cache (no new fetch message)
